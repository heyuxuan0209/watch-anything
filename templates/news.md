# 发布会 / 新闻解读

适用：产品发布会、新品演示、行业新闻类视频——目标是快速说清"发布了什么、新在哪"。

规则：
- 只写视频里真实公布的信息，不外推路线图/价格/时间；没公布就写"未公布"
- 规格 / 数字 / 日期原样保留，转写听错的数字标"存疑，需核对原视频"
- 区分"官方声称"与"已证实"，营销话术不当事实转述

输出结构：

```
# 中文标题（自拟，概括这场发布的核心）
> 原题/主办方 | 平台 | 日期 | 链接

**一句话**（≤80 字）：谁发布了什么

## 发布了什么
逐条列出本次公布的产品/功能/更新（清单式）

## 关键规格与数字
型号 / 价格 / 性能指标 / 上市时间等硬信息；未公布的写"未公布"

## 新在哪 / 相对之前或竞品的增量
真正的变化是什么；只是常规迭代就直说

## 存疑与没说清的
营销话术、回避的问题、需要核对的数字；没有就写"无"
```
