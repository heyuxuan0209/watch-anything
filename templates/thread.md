# Thread 拆解

适用：X 上的连推（thread）、一条信息量很大的长推文，或推文 + 引用推文的组合。

规则：
- 只写推文里真实存在的内容，不外推作者没说的立场
- 附图/附视频未解析时，只依据文字与视频转写解读，不描述画面
- 引用推文单独归属，不和主推混为一谈
- 金句用原文 + 中译

输出结构：

```
# 中文标题（自拟，概括这条 thread 的主张）
> 作者 | 平台 | 日期 | 链接

**一句话主张**（≤80 字）：…

## 逐条脉络
按 thread 的推进顺序梳理作者的论证链（起 → 承 → 转 → 结）

## 关键论据 / 数字 / 例子
值得单独记住的支撑

## 金句
1~2 条原话 + 中译

## 我的判断钩子
2~4 条：这条 thread 可延伸的选题、可质疑的点、可实践的做法

## 局限
作者立场、证据强度、是否只是一家之言；附图/视频若未解析在此声明
```
