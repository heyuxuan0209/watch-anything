# 教程拆解

适用：how-to / 教学 / 上手演示类视频——目标是让人不看视频也能照着做出来。

规则：
- 只写视频里真实演示过的步骤，不补充视频没讲的操作
- 步骤尽量给时间戳（字幕/转写有时间戳时），方便回看某一步
- 命令 / 快捷键 / 参数按原样保留，不臆改；口播里听错的命令名标"存疑"
- 术语首次出现附英文

输出结构：

```
# 中文标题（自拟，概括这个教程教什么）
> 原题/作者 | 平台 | 日期 | 链接

**学完能做到什么**（≤80 字）：…

**前置要求**：需要先装什么 / 会什么；视频没说就写"未提及"

## 步骤拆解
按视频顺序编号，每步一句话说清"做什么"，关键处附 [mm:ss]：
1. …
2. …

## 关键坑 / 提醒
视频里强调过的易错点、注意事项；没有就写"无"

## 一句话总结
把整个流程压成一行，供日后快速回忆
```
